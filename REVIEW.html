Verdict

Approve.

The bug fix is correct and minimal: buildNodeInfoMap was only keying by IP address, so when Prometheus instance labels were hostnames the node-role column was always empty. Adding a node.Name key fixes it. The refactor to extract collectCPUMetricsFromPrometheusClient is well-scoped and the functional test is properly gated for manual use only.

What this PR does

  • Fixes buildNodeInfoMap to also key by node.Name (not just IP and IP:port), so that Prometheus instance labels matching hostnames resolve to the correct node info and populate the node-role column.
  • Deduplicates nodeInfo struct construction — a single value is built per node and reused across all map entries.
  • Extracts collectCPUMetricsFromPrometheusClient from collectCPUMetricsFromPrometheus, separating the client-setup concerns from the metric-collection logic.
  • Adds functional_test.go — an env-var-gated test for driving the collector against real Prometheus/Kubernetes infrastructure during debugging.
