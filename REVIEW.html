OCPBUGS-115153: Make extension test-binary extraction architecture-aware
Head: 52b1048368017eea6fdf4b5794b10522e0f5ca6d · Base: main · Reviewed: 2026-09-01T11:10:24Z

Verdict: approve

The architecture allowlist is applied before extraction, preserves unrestricted binaries, and the follow-up commit correctly uses the CI target architecture rather than the possibly cross-compiled executable architecture.

What this PR does

  • Adds an optional architecture allowlist to payload extension-binary registry entries.
  • Filters payload extension binaries before extraction, preserving entries without an allowlist.
  • Uses OCP_ARCH when CI supplies the control-plane architecture and otherwise falls back to runtime.GOARCH.
  • Marks the vSphere CSI driver extension as amd64-only and covers selection behavior with unit tests.
